# Contributing

Jobs Ireland is a personal project maintained by Christopher Nolan. Ideas and bug reports are welcome as GitHub issues, or by email to chrisnol6073@gmail.com.

How to set it up for development and run its checks is in [DEVELOPMENT.md](DEVELOPMENT.md). A job source must only receive the search itself (keywords, place, country and filters), never anything from the profile, and must be listed in [PRIVACY.md](PRIVACY.md).
